# ALERTES
MVP de prédiction crypto basé sur le machine learning avec génération d'alertes utilisateurs.

Le projet collecte des données de marché depuis Binance, calcule des indicateurs techniques, entraîne un modèle de prédiction, génère des prévisions de marché puis crée des notifications personnalisées pour les utilisateurs abonnés.

## Fonctionnalités

-Collecte automatique de données OHLCV via CCXT. <br>
-Stockage PostgreSQL. <br>
-Feature engineering. <br>
-Entraînement de modèles Machine Learning. <br>
-Génération de prédictions crypto. <br>
-Génération d'alertes utilisateurs. <br>
-API FastAPI. <br>
-Dashboard Streamlit. <br>
-Déploiement Docker. <br>
